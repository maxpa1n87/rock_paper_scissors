# Rock Paper Scissors Game
## This is a smal C program for the game rock paper scissors

### Installation
- Install CMake
- Install a compiler
- Optional install VS Code with CMake and C++ Extensions

Run CMake GUI or commandline
- Create a build directory like "build" inside the source directory
- cd build
- cmake -G \<generator\> \<sourcedir\>
- cmake --build . --config Debug or Release

Run VS code inside source dir
- cd sourcedir
- code .
- Trust folder
- From View -> Command Palette...
- Select CMake: Configure
- Select CMake: Build

Run the binary file
- ./rock_paper_scissors / rock_paper_scissors.exe
